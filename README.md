# Natasha Nuerki Korletey — Creative Portfolio

A static, monochrome portfolio site (plain HTML, CSS and JavaScript, no build step).

- `index.html`: all content
- `styles.css`: design; colours are CSS variables at the top
- `script.js`: sticky header, mobile menu, scroll reveal
- `assets/img/`: photos and project visuals

## Run locally
```bash
npx serve .
```

## Deploy on Vercel
1. Push this repository to GitHub.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other**. Leave the build command and output directory empty, then deploy.
